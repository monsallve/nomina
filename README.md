# Nómina Pro

Aplicación web **local** para gestionar nómina de varias empresas, registrar horas por quincena y generar colillas de pago en PDF.

No requiere servidor. Los datos se guardan en el navegador y puedes **exportar / importar** archivos JSON con el nombre que tú elijas.

## Cómo usar

1. Descomprime el ZIP.
2. Abre `index.html` (o sirve **toda** la carpeta `nomina-pro` en tu servidor local / SHTTPS).
3. Crea empresas y empleados, registra horas y genera colillas.
4. **Exportar**: elige un nombre para el archivo (ej. `nomina_acme_oct2026`) y descárgalo.
5. **Importar**: carga el `.json` que necesites.
